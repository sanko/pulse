Detailed Description

Parser implementation for the Infix language.

The parser uses a recursive descent parsing strategy to build an Abstract Syntax Tree (AST) from the token stream produced by the lexer. It handles:

  • Expression parsing with proper operator precedence
  • Statement parsing (conditionals, loops, function definitions)
  • Class and namespace declarations
  • Error recovery and reporting
