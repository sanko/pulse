Detailed Description

Lexer (tokenizer) implementation for the Infix language.

The lexer is responsible for converting source code text into a stream of tokens that the parser can then consume. It handles:

  • Recognition of keywords and identifiers
  • Numeric literal parsing (integers and floats)
  • String literal parsing with escape sequences
  • Operator and punctuation recognition
  • Whitespace and comment handling
